# How to Choose Between Tables, Figures, and Text

## Use a Table

- To show many precise numerical values and specific data in a small space
- To compare and contrast data values or characteristics among related items with several shared characteristics or variables

## Use a Figure

- To show trends, patterns, and relationships across and between data sets when the general pattern is more important than exact values (graphs, data plots)
- To summarize research results (graphs, data plots, maps, pie charts)
- To present a visual explanation of a sequence of events, procedures, geographic features, or physical characteristics (schematic diagrams, images, photographs, maps)

## Use Text

- When you don't have extensive or complicated data to present
- When the data is peripheral or irrelevant to the main study findings
- When putting data into a table would mean creating a table with 2 or fewer columns
