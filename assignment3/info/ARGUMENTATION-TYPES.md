# Argumentation Types (Argumentation Schemes)

Argumentation types define the relation between an argument and the standpoint it supports. This relation includes an extra, often implicit step: the **bridging premise**.

## Example

| | Example 1 | Example 2 |
|---|---|---|
| **Standpoint** | Socrates is mortal | You should not wear green shirt with purple trousers |
| **Argument** | Socrates is human | Green and purple do not match |
| **(Bridging premise)** | (All humans are mortal) | (If something does not match, you should not wear it) |

Making the bridging premise explicit helps determine the argumentation type.

## Critical Questions

Each argumentation type comes with specific critical questions:

1. **Type 1**: Questions targeting the **content** of an argument (is it true?)
2. **Type 2**: Questions targeting the **justificatory force** (the connection between argument and standpoint — the bridging premise)

## Most Common Argumentation Types

- **Argument from example**: using specific cases to support a general claim
- **Causal argumentation**: claiming a cause-effect relationship
- **Argument from authority**: citing an expert or authoritative source
- **Argument from analogy**: comparing similar situations to draw conclusions
- **Argument from comparison**: using comparative data to support claims
