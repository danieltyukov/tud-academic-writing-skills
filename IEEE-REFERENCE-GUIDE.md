# IEEE Reference Style - Quick Reference Guide

**Source:** `docs/IEEE Reference Style Guide for Authors.pdf`
**Style:** IEEE (numbered references in square brackets)

---

## General Rules

- References are **numbered in order of appearance** in the text: [1], [2], [3]...
- In-text citations use square brackets: [1], [1]-[3], [1, p. 5]
- All authors listed up to 6; for 7+ use "first author et al."
- Titles of articles/chapters in **quotation marks**; titles of books/journals in *italics*
- Abbreviate journal names per IEEE standard
- Always include DOI when available

---

## Most Common Reference Formats

### Journal Article (Periodical)
```
[#] A. Author, B. Author, and C. Author, "Title of article,"
    Abbreviated Journal Title, vol. X, no. Y, pp. start-end,
    Month Year, doi: XX.XXXX/XXXXX.
```
**Example:**
```
[1] J. K. Author, "Name of paper," IEEE Trans. Electron Devices,
    vol. 40, no. 5, pp. 100-120, May 2024, doi: 10.1109/16.494133.
```

### Conference Paper (Published Conference Proceedings)
```
[#] A. Author, "Title of paper," in Proc. Conference Name,
    City, State/Country, Year, pp. start-end.
```
**Example:**
```
[2] D. Author and E. Author, "Title of paper," in Proc. IEEE Int.
    Conf. Circuits Syst., Paris, France, 2023, pp. 45-50.
```

### Book
```
[#] A. Author, Title of Book, xth ed. City, State/Country:
    Publisher, Year.
```
**Example:**
```
[3] B. Razavi, Design of Analog CMOS Integrated Circuits, 2nd ed.
    New York, NY, USA: McGraw-Hill, 2017.
```

### Book Chapter
```
[#] A. Author, "Title of chapter," in Title of Book, xth ed.,
    A. Editor, Ed. City, State/Country: Publisher, Year,
    pp. start-end.
```

### Thesis / Dissertation
```
[#] A. Author, "Title of thesis," M.S./Ph.D. thesis, Dept.,
    Univ., City, State/Country, Year.
```
**Example:**
```
[4] N. Kawai, "Transistor reliability modeling," Ph.D. dissertation,
    Dept. Elect. Eng., Delft Univ. Technol., Delft, Netherlands, 2022.
```

### Website / Online Source
```
[#] A. Author. "Title of page." Website Name. URL
    (accessed Month Day, Year).
```
**Example:**
```
[5] IEEE. "IEEE Reference Guide." IEEE Author Center.
    https://ieeeauthorcenter.ieee.org/ (accessed Feb. 15, 2026).
```

### Technical Report / Standard
```
[#] A. Author, "Title of report," Company/Org, City,
    State/Country, Rep. Number, Year.
```

```
[#] Title of Standard, Standard Number, Corporate Author,
    Year.
```

## In-Text Citation Rules

| Usage | Format |
|-------|--------|
| Single source | [1] |
| Multiple sources | [1], [3], [5] |
| Range of sources | [1]-[4] |
| Specific page | [1, p. 5] |
| Multiple pages | [1, pp. 5-10] |
| Author in sentence | Author [1] showed that... |

### Important Notes
- Place citation **before** the period at end of sentence
- When referencing a specific claim, cite immediately after it
- Every source in the reference list must be cited in the body text (and vice versa)
- Do not use "Ref. [1]" or "Reference [1]" - just use [1]
- Exception: at the start of a sentence, use "Reference [1]" or rephrase

## Formatting Tips

- Journal names are abbreviated (e.g., "IEEE Journal of Solid-State Circuits" becomes "IEEE J. Solid-State Circuits")
- Conference names are abbreviated (e.g., "Proceedings of the IEEE International Conference on..." becomes "Proc. IEEE Int. Conf...")
- Use "et al." only for 7+ authors
- Month names abbreviated to first 3 letters (Jan., Feb., Mar., etc.)
- Page numbers: pp. for range, p. for single page
- Edition: 2nd ed., 3rd ed., etc.
- Volume/number: vol. X, no. Y

---

## Common Mistakes to Avoid

- Missing DOI when one exists
- Inconsistent formatting between references
- Not abbreviating journal/conference names
- Using URLs without access dates
- Not matching in-text citations to reference list
- Forgetting quotation marks around article titles
- Putting book/journal titles in quotation marks instead of italics
