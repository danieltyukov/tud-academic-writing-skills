# Grading Checklist - Literature Review

**Source:** Gradesheet Final paper 2025-2026
**Grading:** Pass / Fail

---

## 1. Requirements Check (Fail if not met)

- [ ] Handed in at deadline via Brightspace
- [ ] 2000 words (+/- 10%), excl. abstract, title, headings, figures/table captions, references, abbreviations
- [ ] Formatted following IEEE guidelines
- [ ] Readable for fellow EE students (not just specialists)
- [ ] Passes plagiarism check (all borrowed ideas/figures cited correctly, IEEE in-text citations)
- [ ] Written in correct English, academic/formal style, minimal errors
- [ ] At least 9 scientific sources of sufficient quality in the body text
- [ ] Contains all required sections (see below)
- [ ] Contains generative AI statement in Acknowledgement

---

## 2. Grading Checklist

### Text Parts

#### Abstract
- [ ] Can be read as a stand-alone text
- [ ] Is informative: includes motivation, objective, method, results/argumentation, main conclusions
- [ ] Key terms are clear to intended readers

#### Objective / Research Question / Aim
- [ ] Presented consistently in Abstract, Introduction, and Conclusion
- [ ] Specific enough
- [ ] Can be answered with a literature study

#### Introduction
- [ ] Contains background information on the problem
- [ ] Indicates motive for research / points out problem and argues why it should be resolved
- [ ] Contains research question or purpose statement linked to motive
- [ ] Contains the method used
- [ ] Indicates structure of the article (unless IMRAD is used)

#### Method
- [ ] Explains which method was used to find suitable sources
- [ ] Explains how results were filtered
- [ ] Formulated so it is replicable

#### Sections in Body Text
- [ ] Divided into functional sections with specific headings
- [ ] Information in sections contributes to conclusion
- [ ] Sections appear in logical order

#### Results
- [ ] Contains a full account of all results (or refers to appendix)
- [ ] Contains tables and graphs to make results clearer

#### Conclusions and Future Prospects
- [ ] Clearly linked to objective in introduction
- [ ] Indicate to what extent research question has been answered
- [ ] Follow logically from all previous material
- [ ] Preferably followed by recommendations for further research

---

### Reference Use

#### Use of Sources
- [ ] Sources are relevant and trustworthy
- [ ] Ideas, fragments, figures, data from other work have correct in-text citations (IEEE)
- [ ] Literal quotations have quotation marks and page numbers
- [ ] Paraphrases are not too close to the original

#### Bibliography / List of References
- [ ] Meets IEEE style requirements
- [ ] Every reference in text corresponds to bibliography entry and vice versa

---

### Argumentation & Structure

#### Argumentation
- [ ] Scientific argumentation model elements clearly recognizable
- [ ] Clear and well structured
- [ ] Reasoning built upon sources
- [ ] Contains critical comparison of multiple sources

#### Storyline
- [ ] Clear storyline/main theme throughout paper
- [ ] Conclusion matches introduction; intermediate sections lead reader from intro to conclusion

#### Paragraphs
- [ ] Well-constructed
- [ ] Not too long; each discusses one topic
- [ ] Clear topic sentence showing topic and link to previous paragraph
- [ ] Clear paragraph structure

---

### Style
- [ ] Correct English: understandable, no spelling errors, acceptable grammar, no lexical mistakes
- [ ] Appropriate academic register: objective, relatively formal, concise
- [ ] Clear and reader-friendly: sentences not too long/complicated, no ambiguity

---

### Illustrations and Layout

#### Tables and Figures
- [ ] All have a number and caption
- [ ] All referred to at least once in text
- [ ] If copied, contain a reference
- [ ] Can be interpreted on their own (e.g., with legend)

#### Format
- [ ] Functional font (type and size)
- [ ] Headings easily recognizable
- [ ] Professional page layout
