- **Referencing:** Always give credit where due. Including references is essential in scientific writing.

## Method Section Guidance

The method section explains in detail how you performed your study. This is important because other researchers need to be able to replicate your study. The scientific community uses it to assess the quality of your work.

**Recommended reading:**
- Silyn-Roberts (2013), Chapter 2: "The Core Chapter: Sections and Elements of a Document" (p. 36), method section in general
- Silyn-Roberts (2013), Chapter 6: "A Journal Paper" (p. 93), method for journal papers
- Academic Phrasebank (University of Manchester) for example sentences to use in the method section

**What the method section should cover (for a literature review):**
- Which databases were searched
- What search terms / keywords were used
- What time range was applied
- How results were filtered (inclusion/exclusion criteria)
- How many sources were retained
- Enough detail that someone else could repeat the search and get similar results

## Checklist: Introduction & Method

### Introduction must contain:
- [ ] Background information
- [ ] A motive
- [ ] An objective
- [ ] A method which:
  - [ ] Explains which method was used to find suitable sources
  - [ ] Explains how results were filtered
  - [ ] Is formulated so that it is replicable
- [ ] A structure overview of the article

### Background / Problem
- [ ] The description of the background / problem is clear to the reader

### Objective
- [ ] There is one clear objective; this objective is:
  - [ ] Argumentative
  - [ ] Specific
  - [ ] Achievable
  - [ ] Oriented on one goal
  - [ ] Objectively formulated
- [ ] The objective stands out in the text (e.g., first sentence of a paragraph)
- [ ] There is a clear link between background, motive, and objective

### Structure & Flow
- [ ] The introduction is clearly structured with paragraphs
- [ ] It is clear how paragraphs are connected

### Sources & References
- [ ] Sources are correctly mentioned where they are used
- [ ] Guidelines for quotations (quotation marks + page number) and paraphrases are correctly applied
- [ ] It is clear to the reader which information is derived from a source
- [ ] References have the correct format (IEEE)

### Formulation
- [ ] **Clear:** explanations can be easily understood, sentences are not too long, descriptions are not vague
- [ ] **Concise:** without resorting to telegram-style
- [ ] **Attractive:** sentence length is varied, examples are used where necessary, sentences are linked with connectives (therefore, in other words, yet) so there is flow in the text
- [ ] **Correct:** no spelling or grammatical errors, correct use of punctuation
- [ ] **Formal:** informal language avoided (no "a lot of", "pretty", "nice"); verbs not contracted ("do not" not "don't"); use of "we" avoided as much as possible
