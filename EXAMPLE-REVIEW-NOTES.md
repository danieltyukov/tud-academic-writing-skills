# Example Literature Review Notes

**Title:** "The tough but bright future of SiC MOSFETs"

**Track:** Microelectronics (ME)

---

## Structure Overview

This example follows IEEE two-column format and includes:

1. **Abstract** - Summarizes the aim (limited SiC MOSFET implementation), the approach (technical + financial aspects), key findings (gate oxide reliability + substrate costs), and conclusion
2. **Index Terms** - High-k dielectric materials, high-temperature, production, silicon carbide MOSFET, silicon carbide wafer
3. **I. Introduction** - Contextualizes the problem (electrification demands), introduces SiC vs Si, states the aim and outlines article structure
4. **II. Example of Better Properties of SiC: High-Temperature Stability** - Background section explaining why SiC is promising
5. **III. The Technical Aspects of SiC MOSFETs** - Main body section with subsections:
   - A. Basic MOSFET structure
   - B. Main technical issue (3 sub-issues: oxide breakdown, SiC/SiO2 interface, FN tunneling)
   - C. Concluding the technical aspects
6. **IV. The Financial Aspects of SiC MOSFETs** - Second main body section:
   - A. Significance of large cost contributors
   - B. Most significant cost contributor
   - C. Issue of main cost contributor
   - D. Concluding the financial aspects
7. **V. Conclusion** - Ties back to the aim, summarizes both technical and financial findings
8. **References** - 14 sources, IEEE style

---

## Key Patterns to Learn From

- **Clear research question stated in introduction and revisited in conclusion**
- **Two-pronged approach:** technical aspects + financial aspects (gives structure to the whole paper)
- **Each body section has its own mini-conclusion** (sections III-C and IV-D)
- **Comparisons are central:** SiC vs Si MOSFETs throughout
- **Knowledge gap identified:** gate oxide reliability + substrate cost as barriers to adoption
- **Future directions mentioned:** high-k dielectric materials as potential solution
- **Figures used:** cost breakdown chart (Fig 1) to support financial analysis
- **IEEE citation style:** numbered references [1], [2], etc.
